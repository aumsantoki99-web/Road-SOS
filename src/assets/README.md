# Assets

Place app assets in this folder.

## Required Files

| File | Size | Used by |
|---|---|---|
| `icon.png` | 1024×1024 | App icon (iOS + Android) |
| `splash.png` | 1284×2778 | Expo splash screen |
| `adaptive-icon.png` | 1024×1024 | Android adaptive icon foreground |
| `favicon.png` | 48×48 | Web browser tab |

## Guidelines

- All icons: transparent background
- Splash: white/dark logo on `#0F172A` background
- Use PNG format
- Optimize before committing (use tinypng.com)

## Placeholder

Until real assets are added, Expo will use its default assets.
The app will launch without errors — the icon/splash will just be default Expo branding.
